# Clinic Management System

A clinic management application built with [Nuxt](https://nuxt.com) and [Nuxt UI](https://ui.nuxt.com).

## Setup

Install the dependencies:

```bash
pnpm install
```

## Development

Start the development server on `http://localhost:3000`:

```bash
pnpm dev
```

## Production

Build the application for production:

```bash
pnpm build
```

Preview the production build:

```bash
pnpm preview
```
